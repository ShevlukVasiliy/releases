# Сценарии использования

## Первый запуск

1. Установите Python 3.10+ и [uv](https://docs.astral.sh/uv/getting-started/installation/).
2. На macOS или Linux с zsh/bash выполните `./scripts/install.sh` и откройте новое окно терминала. Установщик добавит команду `releases` и сохранит резервную копию файла настроек оболочки. Существующий алиас с тем же именем будет перекрыт новой записью в конце файла.
3. Выполните `releases`. Без установки: `uv run python -m releases` из каталога проекта.
4. Нажмите «Обновить медиатеку». По умолчанию сканируется папка Music; другую папку можно задать параметром `--library` при запуске.
5. Если использовались прежние скрипты на этом компьютере, в настройках нажмите «Перенести настройки». Исходные файлы не меняются.

На Windows запуск возможен через `uv run python -m releases --library "C:\\путь\\к\\музыке"`; проверка на Windows пока не проводилась. Установщик оболочки рассчитан на macOS/Linux. Системное хранение токена предусмотрено для macOS и Windows.

## Поиск релизов

В списке слева найдите и отметьте артистов, настройте фильтры и нажмите «Проверить артистов». Результаты появляются по мере проверки. Выбор всех показанных артистов учитывает строку поиска; исключённые артисты не участвуют в проверке. Если найден не тот артист, нажмите «Сопоставить» и укажите числовой ID из ссылки Яндекс Музыки, затем повторите проверку.

Сравнение названий приблизительное, поэтому перед загрузкой стоит просмотреть результаты. Дискографии кэшируются на сутки; автоматическое сопоставление — на 30 дней.

## Загрузка

В настройках сохраните токен Яндекс Музыки. Выберите отдельные релизы или все результаты и нажмите «Скачать выбранные». Кнопка «Загрузить по ссылкам» также принимает список ссылок на альбомы или числовые ID. Ход отображается в очереди. Существующие файлы по тем же именам не перезаписываются; недоступные треки пропускаются. Папка назначения по умолчанию — `~/Music/YandexDump`, её можно изменить параметром `--downloads`.

## Добавление в Apple Music

На macOS у завершённой загрузки нажмите «Добавить в Music». Сервис передаёт файлы приложению Music и не удаляет исходные загрузки. При первом использовании macOS может попросить разрешение на управление Music. В зависимости от настройки копирования в Music треки могут ссылаться на исходные файлы: не удаляйте их, пока не убедитесь, где хранится копия. Если результат попытки неизвестен, повтор заблокирован до ручной проверки, чтобы не создать дубли. Эта интеграция пока не проверена на реальной медиатеке.

## Остановка и данные

Для остановки нажмите Ctrl+C в терминале. База и состояние задач хранятся вне проекта: на macOS — `~/Library/Application Support/Releases`, на Windows — `%LOCALAPPDATA%\\Releases`. Незавершённые задачи помечаются прерванными и автоматически не повторяются. Токен из интерфейса хранится в системном хранилище ключей, а не в базе. Сохранение токена не проверяет его действительность.

## Проверка тегов и порядка треков

В настройках нажмите «Проверить теги» для папки загрузок. В очереди раскройте список предлагаемых изменений. Кнопка применения создаёт рядом с каждым файлом резервную копию с суффиксом `.releases-backup` и пропускает файлы, изменившиеся после проверки. Если резервная копия уже существует, файл не перезаписывается.

На macOS также доступна «Сверить порядок» для библиотеки Music. Сервис ищет точные совпадения альбомов и треков, неоднозначные случаи пропускает. Перед записью покажет предложенные значения; при изменении трека после проверки запись пропускается. Сверка на реальной библиотеке пока не проверена.
